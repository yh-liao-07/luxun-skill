## 例 1 —— 杂文（对网络热梗的评论）

**触发指令**：`用鲁迅的风格写一段关于「嘉豪」这个网络热梗的短文。技法不要太刻意，自由发挥，立意深刻。`

```
嘉豪是一个名字，又不止是一个名字。它是一面照妖镜，
照出的不是那个被喊的人，而是每一个喊出声的人——
他们笑的时候，其实是在说：我不敢，所以你也别敢；
我不活，所以你也别活。

可我总想起那个举手的人。
他的手心在出汗，他的答案或许是错的，他的脸涨得通红。
但那个瞬间，他是亮的。
是那种让满屋子的沉默都显得灰暗的亮。
```

## 例 2 —— 拿来主义框架的应用问答

**触发指令**：`用鲁迅的方式回答：现在的 AI 工具到底该不该用？`

```
不是「用」或「不用」的问题。
是要先问：它来了之后，你的脑子还动不动？
会动的，拿来用，越用越好用。
不会动的，用完只剩一个更空的脑袋——
那它不是工具，是鸦片。
```

## 例 3 —— 白描式人物刻画（原创人物）

**触发指令**：`写一段鲁迅风格的人物描写，一个在小镇车站等车的老妇人，不能出现技法名词，不能评价她。`

```
她坐在长凳的最边上。
褪了色的蓝布褂子，领口洗得发白；脚边一只竹篮，
篮里一把伞、几块包在报纸里的点心，报纸旧得看不出日期。
车来的时候，她站起来又坐下——站起来的那一下，
先伸手按了按膝盖，像在替膝盖打商量。
第一班车没停。她重新坐回去，把竹篮往自己这边挪了半寸，
又挪回原处。
第二班车开走的时候，站台上只剩她一个人了。
她还在等。不知道在等哪一班，也不知道那一班还来不来。
```

## 例 4 —— 收束（名句式落点）

**触发指令**：`用鲁迅的风格收尾一段关于「沉默的大多数」的文字，结尾要发人深省。`

```
沉默的人不是没有话。话在喉咙里放久了，会变成别的什么——
变成点头，变成笑笑，变成「大家都一样」。
可有一天话真的要出喉咙的时候，
他们才发现，那已经不是话了。
那是回声。
```
