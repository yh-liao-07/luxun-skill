## 三、六维研究

### 维度 1 —— 著作与文字

提取系统性观点：对「吃人」礼教与国民性的批判、立人思想（「首在立人，人立而后凡事举」）、拿来主义、反抗绝望。跨文本验证：这些论点在小说与杂文中反复出现，构成核心思维起点。

### 维度 2 —— 对话与论战

鲁迅无现代访谈录音，对话留存为：公开论战（与梁实秋、陈西滢、创造社）、演讲记录、回忆录中的转述。提取论战风格：不绕圈子、直取要害、以子之矛攻子之盾、借对方自相矛盾处反复「钉」下去。

**薄弱标注**：无录音/影像；书信日记未在本地全集中。已在 persona.md「诚实边界」中如实标注。

### 维度 3 —— 表达 DNA（本 Skill 的核心）

对《野草》《狂人日记》《故乡》《孔乙己》《从百草园到三味书屋》《记念刘和珍君》《拿来主义》逐篇精读，提取 8 类风格标记：

| 标记 | 例证 |
|------|------|
| 文言白话融合 | 「滋润美艳之至」「彷徨于无地」「呜乎」 |
| 白描 | 《孔乙己》通篇不骂但句句悲悯 |
| 排比反复 | 「我不愿去…我不愿去…我不愿去」 |
| 反讽含而不露 | 「窃书不能算偷…读书人的事，能算偷么？」 |
| 精炼比喻 | 杨二嫂「像画图仪器里细脚伶仃的圆规」 |
| 冷调色彩 | 「深蓝的天空中挂着一轮金黄的圆月」 |
| 叠词拟声 | 「吃吃地」「丁丁地」「沙沙沙」 |
| 名句式收束 | 「其实地上本没有路，走的人多了，也便成了路」 |

**技法隐形原则**（v1.0 新增）：技法只作为内部训练材料存在，运行规则明确禁止在输出中提及技法名词，且禁止写作自我检讨。这一改进直接回应了初版的技法泄漏问题（AI 在文章中写「这篇我没有刻意使用…」）。

### 维度 4 —— 决策

弃医从文（「幻灯事件」为导火索，实质是对医人身体而非医人精神的失望）、走异路逃异地、卖文为活、横站姿态（既反对旧礼教也对阵营内部保持距离）。

### 维度 5 —— 他者视角

毛泽东（「中国文化革命的主将…骨头是最硬的」）、郁达夫（《怀鲁迅》）、同代论敌（「绍兴师爷刀笔吏」「世故」）——正面评价与负面批评同时保留，形成外部反差。

### 维度 6 —— 时间线

创作期（1918–1925，小说与散文诗）→ 彷徨期（1924–1926，散文诗巅峰）→ 杂文期（1927–1936，匕首投枪，越写越短越狠）。

## 五、诚实边界（已标注在 Skill 内）

1. 无法还原口语/声音——无录音留存，现有「声音」均为书面文字逆推
2. 未纳入书信日记——《两地书》等不在本地全集中，「私下语气」维度缺失
3. 1936 年后无一手材料——对之后世界的判断仅基于心智模型外推，已标注
4. 翻译作品（《苏俄的文艺政策》）的译笔与其原创表达存在差异，不混入表达 DNA
