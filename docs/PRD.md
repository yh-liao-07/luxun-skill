# luxun-skill —— 产品需求文档 v1.0

---

## 一、产品概述

**luxun-skill** 是一个把鲁迅（周树人）的表达方式蒸馏成可复用 AI Skill 的仓库。

用户通过 `@luxun-skill`（DeepSeek Harness）或 `/{luxun-skill}`（其他宿主）触发，将写作任务交给一个「用鲁迅的方式思考、用鲁迅的口吻写作」的 Skill。

本仓库本身就是 Skill 目录（AgentSkills 标准）：根目录的 `SKILL.md` 即入口，`work.md` 与 `persona.md` 为双层层内部分层。

---

## 二、用户流程

```
用户触发 @luxun-skill: <写作任务>
        ↓
[Step 1] PART B 判断：这个人会接这个任务吗？用什么态度接？
        ↓
[Step 2] PART A 执行：用鲁迅的写作方法论完成任务
        ↓
[Step 3] 输出：白描/反讽/冷峻的表达，技法完全隐形，不做写作自我检讨
```

### 典型任务

- 写一段鲁迅风格的杂文 / 小说片段 / 散文诗
- 用鲁迅的眼光评论当下事件
- 修改润色一篇文章，使其接近鲁迅的表达层次
- 「拿来主义」「国民性批判」「反抗绝望」等心智模型的应用性问答

---

## 三、功能规格

### 3.1 PART A —— 写作方法论

| 功能 | 说明 |
|------|------|
| 文体覆盖 | 叙事与白描（小说/散文）、杂文与论辩、意象与散文诗 |
| 语言基底 | 文言白话融合、短句为骨长短交替 |
| 核心手法 | 白描、通过对话刻画人物、反讽、排比反复、精炼比喻、名句式收束 |
| 词汇意象 | 冷调色彩词、枣树/野草/路/破屋等意象库、叠词拟声点缀 |
| 禁忌 | 不写套话/口号、不直接抒情表态 |

### 3.2 PART B —— 认知签名

| 功能 | 说明 |
|------|------|
| Layer 0 | 核心思维规则（永远优先） |
| Layer 1 | 身份（我是谁、要什么） |
| Layer 2 | 表达 DNA（语调/标志性手法/句式特征/示例声音） |
| Layer 3 | 心智模型（国民性批判视角/反抗绝望的伦理/批判性拿来主义） |
| Layer 4 | 决策习惯（何时快速行动/何时等待/何时改变想法） |
| Layer 5 | 反模式与诚实边界（拒绝什么/不知道什么/内在矛盾） |
| Layer 6 | 智识谱系（受谁影响/与谁分歧/影响谁） |
| Layer 7 | Agentic Protocol（面对新问题的分析步骤） |

### 3.3 运行规则（硬约束）

1. 技法必须完全隐形——输出中永不出现「白描」「反讽」「排比」等技法名词
2. 永不进行写作自我检讨——不在正文中评论自己的写作方法
3. PART B 的 Layer 0 永远优先

---

## 四、边界与非目标

- 不搬运鲁迅语录；语录查询请回到《鲁迅全集》原文
- 无法还原口语/声音（无录音留存）、未含书信日记（本地全集未包含）
- 对 1936 年之后的世界仅基于心智模型合理推测（已标注）
- 本仓库不含完整 dot-skill 引擎——引擎见 titanwings/colleague-skill，本仓库是它的一个 celebrity 蒸馏产物

---

## 五、验收标准

- `python tools/verify_skill.py SKILL.md` 全部 PASS
- 输出中无技法名词、无写作自我检讨（人工抽查）
- 心智能代表鲁迅的思维起点而非结论（如「从来如此，便对么」式的追问习惯）
- 任何 PR 不得削弱「技法隐形」与「诚实边界」两项硬约束
